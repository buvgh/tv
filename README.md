# 枫林晚TV

枫林晚TV 是一个基于 Android 的聚合影视播放器项目，支持多订阅源导入、首页推荐、全局搜索、详情聚合、在线播放、后台下载、收藏、历史记录和播放器增强功能。

- `versionName`: `1.8.12`

## 主要功能

- 多订阅源导入、切换与刷新
- 首页热门推荐与分类筛选
- 片名、演员、导演等关键词搜索
- 详情页多线路聚合与剧集切换
- 播放失败自动切换可用线路
- 收藏、历史、下载管理
- 后台下载、批量下载、失败重试
- 已观看进度记录与进度条展示
- 播放器手势控制、横竖屏切换、小窗播放
- 成人内容过滤与隐藏开关

## 最新更新

- 统一优化了首页、订阅板、详情页、下载页在不同手机尺寸下的自适应布局
- 订阅板底部版本号与关闭按钮固定显示，小屏按钮自动换成竖排
- 详情页窄屏下改为更稳的海报上下布局，播放/下载按钮会按屏宽自动切换横排或竖排
- 下载页卡片、分组卡片、批量操作在小屏设备上显示更稳定

## 开发说明

项目使用 Android Studio 与 Gradle 构建。

本仓库不包含发布签名密钥。`release` 签名配置通过本地环境变量或 `local.properties` 注入：

- `RELEASE_STORE_FILE`
- `RELEASE_STORE_PASSWORD`
- `RELEASE_KEY_ALIAS`
- `RELEASE_KEY_PASSWORD`
